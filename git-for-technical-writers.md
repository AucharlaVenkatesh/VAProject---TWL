# Git for Technical Writers

Git helps technical writers manage documentation changes and collaborate with engineering teams.

## Why Technical Writers Use Git

- Track documentation changes
- Maintain version history
- Collaborate with developers
- Review changes through Pull Requests
- Work safely using branches
- Integrate documentation with software development workflows

## Typical Documentation Workflow

1. Create a documentation branch.
2. Update the documentation.
3. Commit the changes.
4. Push the branch to GitHub.
5. Create a Pull Request.
6. Get the documentation reviewed.
7. Merge the approved changes.
